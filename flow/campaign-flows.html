0Before any chat: what the brand needs in Polysocial

Set up once in the brand web app. check_brand_connection and get_brand_profile read these at the start of every chat, and publish_campaign is blocked without them.

🔌Connector added in Claude

  • Polysocial MCP connector connected
  • Signed in to the brand's Polysocial workspace
  • Brand verified
Claude · Settings → Connectors

🏷️Brand profile

  • Brand name and logo, cover
  • Category, website, location
  • About (what creators see)
  • Social accounts: Instagram, TikTok, Facebook, YouTube, LinkedIn
Brand web app · #/profile/brand

👥Team access

  • You are Full admin or Can edit to create and publish
  • View only can read but not publish
  • At least one active full admin
Brand web app · #/profile/team

💳Funded wallet

  • Add funds by bank transfer, with the payment reference
  • Upload the transfer slip (PDF/JPG/PNG ≤ 10 MB)
  • Only verified transfers count; free-to-spend balance ≥ campaign budget
Brand web app · #/financials/funds

🏦Bank details

  • Account holder, bank, branch, account number
  • Where Polysocial refunds unspent budget
  • Only the brand can add or edit them
Brand web app · #/profile/account

3Go-live gates (all three paths)

What has to be true before Claude asks for permission to publish.

Gate 1Brand connected

check_brand_connection · verified, admin or can edit

Gate 2Design done

Brief from the brand, Claude or the approved strategist design

Gate 3Cover & inspiration

Always from the brand; inspiration reels must be public

Gate 4Budget set & funded

Verified wallet balance ≥ the amount to hold

Gate 5Validated

validate_campaign · no missing fields or warnings

Gate 6Brand approves

Permission prompt for publish_campaign, then the budget is held
